# motion.md

우리 서비스의 움직임 기준. 성격은 **경쾌함**: 짧게 움직이고 빠르게 감속하며, 튕기지 않고 탁 안착한다. 컷 대신 앞 요소가 다음 장면이 된다.
규칙: 이 문서에 있는 값만 쓴다. 단위는 프레임(f, 30fps 기준)이고 ms는 참고값이다. 장면 순서와 화면 배치는 여기에 쓰지 않는다. 영상마다 비트 시트에 쓴다.
색 · 글자 · 로고는 [design.md](design.md)를 따른다. 레퍼런스에서는 가져오지 않았다.

**출처** (받은 파일과 출처: `references/`, 목록은 `references/sources.md`)
- **A** `remotion-device-rise.mp4`: 문서 "Remotion Prompts · Apple-Style Device Rise Animation" (1280×720 · 30fps · 4s). 값은 **문서 값**이다.
- **B** `skillry-saadpastadev-347341.mp4`: @SaadPastaDev Nafa 영상 (1280×720 · 30fps · 24.5s). 공개된 프롬프트에 수치가 없어서 **프레임 실측**으로 값을 뽑았다.
- 시점 표기는 `영상 mm:ss 무엇 길이 (시작f→끝f)`로 쓴다. 실측값은 ±1f 오차가 있다.

## 1. Primitives

### 길이 (duration)

| 변수 | f | ms | 레퍼런스 시점 |
|---|---|---|---|
| `duration-4` | 4 | 133 | B 00:05 검색어 한 글자 4f (f162→166) · B 00:17 회사 이름 롤 4f (f518→522) · B 00:05 휴대폰→검색창 줌 컷 4f (f156→160) |
| `duration-6` | 6 | 200 | B 00:00 첫 단어 커지며 등장 6f (f2→8) · B 00:14 알림 내려옴 6f (f438→444) · B 00:16 알림→검은 면 6f (f482→488) |
| `duration-9` | 9 | 300 | A 00:01 알림 카드 간격 0.3s (문서) · B 00:09 다음 화면으로 디졸브 8f (f294→302) · B 00:06 검색창→점 9f (f188→196) |
| `duration-12` | 12 | 400 | B 00:02 휴대폰 아래에서 올라옴 12f (f84→96) · B 00:09 화면 스크롤 12f (f278→290) · B 00:03 로고→목록 아이콘 12f (f100→112) |
| `duration-18` | 18 | 600 | B 00:12 버튼 옆에서 미끄러져 들어옴 18f (f364→382) · B 00:01 로고 날아와 안착 18f (f52→70) · B 00:12 스와이프 채움 16f (f388→404) |
| `duration-45` | 45 | 1500 | A 00:00 기기 솟아오름 1.5s (문서) · B 00:14 카메라 밀고 들어감 44f (f444→488) |

### 곡선 (curve)

| 변수 | 값 | 레퍼런스 |
|---|---|---|
| `curve-out` | `cubic-bezier(0.33, 1, 0.68, 1)` (ease-out cubic) | A: 문서에 "모든 애니메이션 `Easing.out(Easing.cubic)`"으로 적혀 있음. B: 등장할 때 첫 1~2f에 대부분 이동하고 끝에서 멈춤 |
| `curve-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` (ease-in-out cubic) | B 00:14 카메라 밀고 들어감: 느리게 출발해서 가운데가 빠르고 끝에서 느려짐 (f444→488) |
| `curve-in` | `cubic-bezier(0.32, 0, 0.67, 0)` (ease-in cubic) | B 00:21 마지막 문장 어두워지며 퇴장 6f (f655→661): 처음 느리고 끝이 빠름 |
| `curve-linear` | `linear` | B 00:05 타이핑 4f 간격 일정 · B 00:12 스와이프 채움 속도 일정 |

- 반동(overshoot) · 스프링 곡선은 **없다**. 두 레퍼런스 모두 튕기지 않았다.

## 2. Semantic

| 변수 | 길이 | 곡선 | 쓰는 곳 | 레퍼런스 시점 |
|---|---|---|---|---|
| `motion-tick` | `duration-4` | `curve-linear` | 글자 하나, 숫자 바뀜, 롤 한 칸 | B 00:05 검색어 타이핑 4f · B 00:17 회사 이름 롤 4f |
| `motion-pop` | `duration-6` | `curve-out` | 작은 요소 등장 (단어, 배지, 알림), 퇴장할 때는 `curve-in` | B 00:00 첫 단어 6f · B 00:14 알림 6f |
| `motion-swap` | `duration-9` | `curve-in-out` | 같은 자리에서 바뀜 (디졸브, 상태 전환, 모양 바뀜) | B 00:09 화면 디졸브 8f · B 00:06 검색창→점 9f |
| `motion-enter` | `duration-12` | `curve-out` | 카드 · 휴대폰 화면 등장, 스크롤 | B 00:02 휴대폰 올라옴 12f · B 00:09 스크롤 12f |
| `motion-travel` | `duration-18` | `curve-out` | 멀리서 들어옴, 진행 바 · 채움 | B 00:12 버튼 들어옴 18f · B 00:01 로고 안착 18f |

- 나란한 요소를 순서대로 띄울 때 **간격(stagger)은 `duration-9`**. 출처: A 00:01 알림 카드 0.3s 간격 (문서)
- `duration-45`는 Semantic에 두지 않는다. 5장 카메라에서만 쓴다.

## 3. Pattern (`src/parts` · `src/screens`)

| 대상 | 움직임 | 토큰 | 레퍼런스 시점 |
|---|---|---|---|
| `button-submit` 등장 | 옆에서 미끄러져 들어와 안착 | `motion-travel` | B 00:12 버튼 들어옴 18f (f364→382) |
| `button-submit` 누름 | 왼쪽부터 채움, 그다음 `data-state` 문구 바뀜 | 채움 `motion-travel`(곡선만 `curve-linear`) → 문구 `motion-swap` | B 00:12 채움 16f (f388→404) → 상태 바뀜 (f406→414) |
| `badge-approved` | 작게 시작해서 커지며 등장 | `motion-pop` · 크기 **새 후보** | B 00:14 완료 체크 아이콘 커짐 (f420→430) |
| `skill-card-1~3` 목록 | 한 장씩 차례로 등장 | `motion-enter` + 간격 `duration-9` | A 00:01 알림 카드 차례로 등장 0.3s (문서) |
| `mission-card` 진행 바 | 0에서 값까지 채움 | `motion-travel` | B 00:12 스와이프 채움 (f388→404) |
| `stat-card` 금액 | 숫자가 한 자리씩 바뀜 | 자리마다 `motion-tick` · 전체 길이 **새 후보** | B 00:06 가격 숫자 바뀜 (f208→232, 6~8f 간격) · B 00:10 금액 입력 |
| `asset-card` `data-state` 4개 | 같은 자리에서 상태 바뀜 | `motion-swap` | B 00:09 화면 디졸브 8f (f294→302) |
| `brand-icon` · `logo` | 앞 장면이 퇴장한 뒤 커지며 등장, 보조 글줄은 뒤따라 페이드 | 퇴장 `motion-pop`(`curve-in`) → 로고 `motion-pop` → 글줄 `motion-pop` | B 00:21 퇴장 6f (f655→661) · B 00:22 커짐 (f664→668) · 글줄 6f (f670→676) |
| 부품 → 다음 장면 | 앞 장면의 부품이 다음 장면의 일부로 모양이 바뀜 (컷 대신) | `motion-swap` 또는 `motion-enter` | B 00:03 로고→목록 아이콘 12f · B 00:06 검색창→점→그래프 선 (f188→204) |
| `screens` 화면 안 스크롤 | 한 번에 스크롤해서 다음 영역으로 | `motion-enter` | B 00:09 상세 화면 스크롤 12f (f278→290) |
| `screens` 화면 바꿈 | 디졸브 | `motion-swap` | B 00:09 상세→주문 화면 8f (f294→302) |
| 글줄 단어 하나씩 | 단어 붙음 · 바뀜 | 단어마다 `motion-pop` | B 00:00 "첫 단어" f2 → 다음 단어 f10 → f30 → f38 |
| 이름 롤 | 세로로 한 칸씩 굴러감. 머무는 시간이 점점 짧아짐 | 롤 `motion-tick` | B 00:17~00:21 롤 4f, 간격 12f → 8f → 7f |

**새 후보** (레퍼런스에 숫자가 없음. 쓰기 전에 값을 정해야 함)
- `badge-approved` 처음 크기: A 문서 값 `scale 0.8 → 1.0`을 그대로 쓸지?
- `stat-card` 숫자가 올라가는 전체 길이: `duration-18`? `duration-45`?
- 등장할 때 움직이는 거리(px): A 문서는 `translateY 400px`(기기 전용)뿐이다. 부품용 거리는 없음.

## 4. 머무는 시간 (hold)

움직임이 끝난 뒤 다음 움직임이 시작되기 전까지의 시간.

| 변수 | f | 쓰는 곳 | 레퍼런스 시점 |
|---|---|---|---|
| `hold-breath` | 6 | 다음 동작 직전의 숨 | B 00:12 버튼 안착 → 채움 6f (f382→388) · A 00:01 기기 안착 → 알림 5f (f45→50) |
| `hold-beat` | 12 | 단어, 짧은 글줄 하나 | B 00:01 둘째 문장 12f (f38→50) · B 00:05 검색어 완성 뒤 10f (f174→184) |
| `hold-line` | 24 | 한 문장 다 읽기 | B 00:21 마지막 문장 22f (f633→655) · B 00:00 두 단어 문장 18f (f10→28) |
| `hold-screen` | 60 | 화면 하나 읽기, 엔딩 | B 00:07 상세 화면 68f (f210→278) · B 00:22 엔딩 60f (f676→736) · A 00:02 마지막 45f (f75→120) |

- 이름 롤처럼 반복되는 요소는 머무는 시간을 `hold-beat`(12)에서 시작해 7f까지 줄여 속도를 높인다. 출처: B 00:17~00:21

## 5. 카메라

| 변수 | 움직임 | 길이 · 곡선 | 레퍼런스 시점 |
|---|---|---|---|
| `camera-rise` | 기기 화면이 아래에서 솟아오름. `translateY 400px → 0`, `rotateX 35° → 8°`, `scale 0.8 → 1.0`, 기준점은 아래 가운데 | `duration-45` · `curve-out` | A 00:00 기기 솟아오름 1.5s (**문서 값**, 순서 translateX → translateY → rotateX → scale) |
| `camera-push` | 화면 쪽으로 천천히 밀고 들어감 (약 1.4배, 실측) | `duration-45` · `curve-in-out` | B 00:14 완료 화면으로 밀고 들어감 44f (f444→488) |
| `camera-match-zoom` | 부품 하나로 확 들어가서 그 부품이 다음 장면이 됨 | `duration-4` · `curve-out` | B 00:05 휴대폰→검색창 4f (f156→160) |
| `camera-pull-out` | 부품에서 빠져나와 전체 화면을 보여 줌 | `duration-6` · `curve-out` | B 00:06 그래프 선→휴대폰 화면 6f (f204→210) |
| `camera-wipe` | 부품이 커져서 화면을 덮고, 덮은 순간 컷 | `duration-6` · `curve-in` | B 00:16 알림이 검은 면으로 커짐 6f (f482→488), 컷 f490 |

- 흔들기 · 기울이기는 쓰지 않는다. 회전은 `camera-rise`의 `rotateX`에서만 쓴다.
- `camera-push`의 1.4배는 실측 근삿값이다. 다른 배율이 필요하면 **새 후보**로 정한다.
